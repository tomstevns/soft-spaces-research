# Fase 2-artikelskabelon

Denne mappe er reserveret til den korte afsluttende fase 2-artikel.

Den endelige LaTeX-kilde fra fase 1 er endnu ikke tilgængelig i denne overdragelse. Når Tom uploader `.tex`-filen samt eventuel `.bib`, `.sty` og figurer, skal en kopi placeres her og bruges som layoutskabelon. Selve fase 2-teksten bør redigeres i en ny fil, så fase 1-kilden bevares uændret.
