MAPPING ELIGIBILITY GATE
------------------------
Before calculating any geometry:

- use GPL570 platform annotation only;
- map probes to gene symbols deterministically;
- arithmetic mean across multiple probes mapping to the same frozen gene;
- all 12 frozen genes must be reproducibly measurable in GSE159472.

If fewer than 12 frozen genes are reproducibly measurable:
    v41.16 = TECHNICALLY NON-EVALUABLE

No reduced-panel rescue is allowed within v41.16.
Any such analysis would require a separately versioned exploratory protocol.

PREPROCESSING
-------------
For GSE10846 and GSE159472 separately:

1. processed expression values as supplied by GEO / existing frozen pipeline;

   probes map to the same gene;
4. cohort-wise z-standardization gene by gene;
5. no ABC/GCB, outcome, treatment, survival, response, or other disease labels
   are used in the geometry calculation.

PRIMARY DECISION RULE
---------------------
v41.16 confirmatory PASS if and only if:

1. REAL S4 > NULL mean; AND
2. empirical one-sided p <= 0.05

where:

    p = (1 + #{NULL S4 >= REAL S4}) / (1 + N_NULL)

Otherwise:
- if the mapping gate passed but this rule fails: CONFIRMATORY FAIL;
- if the mapping gate fails: TECHNICALLY NON-EVALUABLE.

No endpoint substitution, tuning of r, gene removal, normalization change, or
NULL redefinition is allowed after expression results are viewed.

Secondary support:
    REAL > NULL mean AND empirical one-sided p <= 0.05

Secondary outcome does not change the primary PASS/FAIL decision.
