SOFT SPACES / DLBCL
v41 RESEARCH HISTORY
Frozen research record through v41.11b

Purpose
-------
This file preserves the methodological and scientific history of the DLBCL
application track in Soft Spaces Phase 4.

It records:
- why each version was created,
- what methodological problem it addressed,
- what failed,
- what was corrected,
- what evidence was obtained,
- what decisions followed,
- which stages were exploratory,
- which stages were external validation,
- which stages were blind/prospective.

===============================================================================
0. OVERALL RESEARCH QUESTION
===============================================================================

Can the Soft-Spaces formalism, originally developed in a quantum/Hilbert-space
context, be repurposed as a feature-ranking / subspace-discovery method for
high-dimensional biological data?

Initial biological test case:
Diffuse Large B-Cell Lymphoma (DLBCL), especially ABC versus GCB.

The key question was not whether ABC and GCB can be classified at all.
Classical bioinformatics already does that well.

The relevant question was:

Can Soft Spaces identify a compact, transferable and non-random feature
subspace that preserves strong biological classification information?

3. v41.1 / v41.1a — INITIAL PREPROCESSING
===============================================================================

Main role
---------
Construct the patient-by-feature matrix and implement the first preprocessing
pipeline.

Approximate dimensionality
--------------------------
~22,000 measured transcriptomic features per patient before reduction.

Operations included
-------------------
- expression matrix construction
- filtering
- scaling / normalization
- initial feature reduction
- preparation for Soft-Spaces ranking

Scientific role
---------------
EXPLORATORY / DEVELOPMENT.

Important later finding
-----------------------
This preprocessing chain contained a real methodological error:
feature variance/ranking had been performed after scaling.

Because standardization changes the variance structure, the original raw
variance information had effectively been destroyed before variance-based
selection.

This flaw became the motivation for v41.7.

13. v41.10 — CROSS-COHORT ALIGNMENT AUDIT
===============================================================================

Main role
---------
Investigate development-versus-external expression scale differences.

Key finding
-----------
A cohort-scale shift was identified.

Interpretation
--------------
Relative ranking information could remain useful even when absolute prediction
scores shifted across cohorts.

Solution
--------
Introduce a label-free cohort standardization.

Representative external performance after label-free alignment
---------------------------------------------------------------
Approximate AUC:
0.8279

Approximate balanced accuracy:
0.7510

Scientific role
---------------
EXTERNAL ALIGNMENT / TRANSFER CORRECTION.

Important methodological point
------------------------------
External disease labels were not used to optimize the alignment.

Decision
--------
Freeze the corrected/aligned pipeline and test prospectively on a new cohort.

16. CURRENT 16-GENE INTERPRETATION
===============================================================================

Practical result
----------------
~22,000 measured transcriptomic features
    ->
Soft-Spaces ranking / feature discovery
    ->
16-gene feature panel
    ->
strong ABC/GCB discrimination
    ->
successful independent blind external validation

Supported claim
---------------
A Soft-Spaces-derived feature-ranking procedure identified a compact 16-gene
structure in a development cohort that retained strong ABC/GCB information and
transferred successfully to an independent external cohort under a frozen,
label-blind evaluation procedure.

Not supported
-------------
- The 16 genes are not proven causal DLBCL drivers.
- Soft Spaces is not proven superior to all classical bioinformatics methods.
- No clinical diagnostic validation has been established.
- No quantum computational advantage has been demonstrated.

18. WHAT HAS BEEN ESTABLISHED
===============================================================================

1. Soft-Spaces-derived feature ranking can reduce a high-dimensional DLBCL
   transcriptomic problem to a compact feature panel.

2. The 16-gene structure carries strong ABC/GCB classification information.

3. REAL outperforms matched/randomized NULL controls in the corrected pipeline.

4. The structure transfers to independent patient cohorts.

5. Cross-cohort scale differences materially affect transfer and must be handled.

6. Label-free cohort alignment can restore useful transfer without tuning on
   external disease labels.

7. The strongest test used a frozen pipeline and label-blind GSE87371
   prediction procedure.

8. On 168 unambiguous ABC/GCB patients, REAL achieved approximately
   AUC 0.9562 and balanced accuracy 0.8867.

===============================================================================
19. WHAT HAS NOT BEEN ESTABLISHED
===============================================================================

The present work does not establish:

1. superiority over the best classical bioinformatics methods;
2. causal biological roles for the 16 genes;
3. clinical diagnostic validity;
4. generalization to every DLBCL cohort or assay platform;
5. universal applicability to all biological datasets;
6. quantum computational advantage;
7. any requirement for quantum hardware in the biological application.

===============================================================================
20. CURRENT SCIENTIFIC STATUS
===============================================================================

The DLBCL application has progressed beyond a toy demonstration.

The strongest current interpretation is:

Soft Spaces appears to function as a compact feature-discovery / feature-ranking
method in high-dimensional DLBCL transcriptomic data.

The strongest evidence is not merely the high GSE87371 AUC.

The methodological history matters:

- an external failure occurred,
- the failure was not hidden,
- a real preprocessing error was identified,
- the pipeline was corrected,
- a second transfer problem was diagnosed,
- cohort alignment was introduced without test-label tuning,
- the pipeline was frozen,
- predictions were generated before labels were opened,
- prediction integrity was verified,
- strong external performance was then observed.
