PREREQUISITES

v43.2:

FROZEN INTERNAL REPRESENTATION
------------------------------
Development cohort:
    GSE130404

Frozen direct-subspace rank:
    r = 16

Internal representation:
    X -> H -> U_16 -> direct projection

No top-K gene selection is permitted.

PURPOSE
-------
Test whether the frozen Soft-Spaces representation learned from GSE130404
generalizes to an independent CML cohort.

EXTERNAL COHORT
---------------
GSE44589

Known cohort structure from the prior CML audit:
    198 arrays total
    135 pretreatment baseline samples
    63 post-6-week samples

Frozen external analysis population:
    PRETREATMENT BASELINE ONLY

Post-6-week samples are excluded from the primary external test.

Frozen baseline response availability:
    69 MMR
    59 none
    7 unavailable

Primary evaluable baseline set:
    128 samples with response label available

EXTERNAL ENDPOINT
-----------------
GSE44589 uses molecular-response labeling:

    MMR
    none

This is NOT identical to the GSE130404 development endpoint:

    BCR-ABL1 >10% IS vs <10% IS at 3 months

Therefore v43.4/v43.5 is explicitly defined as:

    CROSS-ENDPOINT TKI-RESPONSE GENERALIZATION

It must NOT be described as an exact external replication of the
GSE130404 3-month EMR endpoint.

FROZEN LABEL CODING
-------------------
External positive class:
    molecular response = none

External negative class:
    molecular response = MMR

Unavailable response:
    excluded

Rationale:
    The positive class continues to represent poorer treatment response,
    matching the direction used in GSE130404 where y=1 denotes EMR failure.

TRAINING / TESTING PRINCIPLE
----------------------------
The external cohort must not influence:

- rank r;
- development gene-pool selection;
- classifier family;
- hyperparameters;
- feature-ranking rule;
- choice of performance metric;
- orientation of the positive class.

All learnable quantities must come from GSE130404.

NO EXTERNAL RETUNING
--------------------
Forbidden after viewing external outcomes:

- changing r;
- selecting a new gene subset;
- changing classifier;
- changing class weights;
- changing thresholds to improve performance;
- choosing genes because they exist on GSE44589;
- outcome-guided platform mapping;
- redefining MMR/none;
- including post-6-week samples to improve results.

PLATFORM / GENE-MAPPING RULE
----------------------------
Before external outcome evaluation:

1. map the frozen GSE130404 representation genes to GSE44589/GPL570;
2. determine technical measurability without using external response labels;
3. report all missing genes;
4. construct the external representation only from genes measurable in both
   cohorts.

If the frozen representation cannot be transported without materially changing
its definition, the external test is TECHNICALLY NON-EVALUABLE.

No replacement genes may be chosen after outcome inspection.

IMPORTANT REPRESENTATION ISSUE
------------------------------
The v43 representation is a learned subspace, not a fixed top-gene list.

Therefore v43.5 must preserve the development-trained basis as far as platform
compatibility allows.

For each development training construction:

    U_16 is learned in development gene coordinates.

The external sample matrix must be mapped into the SAME coordinate system.

If some coordinates are absent externally:
    do not silently impute biological replacements.

A separate technical transport audit must state whether the frozen subspace
can be evaluated faithfully.

PRIMARY EXTERNAL METRIC
-----------------------
PR-AUC

Secondary:
    ROC-AUC
    balanced accuracy
    sensitivity
    specificity

PRIMARY EXTERNAL CLAIM
----------------------
The primary question is:

    Does the frozen v43 direct-subspace representation retain predictive
    information for independent pretreatment TKI-response status in GSE44589?

PRIMARY SUCCESS RULE
--------------------
Because the external endpoint is related but non-identical, v43.5 is a
generalization test rather than exact replication.

A primary external PASS requires:

1. PR-AUC above the external positive-class prevalence baseline; AND
2. ROC-AUC > 0.5; AND
3. the predictive direction is consistent with development
   (higher score = poorer response); AND
4. performance is not generated by post-hoc tuning.

No p-value threshold is preregistered here as a sole determinant of PASS,
because v43.5 is a single independent cross-endpoint cohort test.

All uncertainty measures must be reported.

COMPARATOR
----------
The frozen v43 direct-subspace model must be reported alongside:

- external prevalence PR-AUC reference;
- a simple classical comparator if technically feasible without retuning.

Any comparator must be labeled secondary.

The external test does NOT need to exceed the v42.2 internal SVM to establish
cross-endpoint generalization.

NO CLAIMS BEYOND EVIDENCE
-------------------------
Even a positive v43.5 result would not establish:

- clinical utility;
- treatment recommendation;
- causal genes;
- exact 3-month EMR replication;
- superiority over established CML biomarkers;
- quantum advantage.

TECHNICAL STOP RULE
-------------------
If platform mapping does not support faithful transport of the frozen
representation, record:

    TECHNICALLY NON-EVALUABLE

Do not modify the representation to rescue the test.

SCIENTIFIC STOP RULE
--------------------
If the frozen representation does not generalize:

    record FAIL
    do not retune on GSE44589
    close the v43 CML branch unless a separately motivated new hypothesis is
    preregistered.
